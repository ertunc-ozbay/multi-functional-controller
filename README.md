# Multifunctional Controller Project(In Progress)

A custom handheld controller that built for both gaming and conrolling RC devices,
**NOTE:** This project is still in development and some features and modules could be changed in the future. 

##FEATURES

**-Low latency on both bluetooth and radio signal connection**
**-----New features will be added in the future-----**


##COMPONENTS

**-High performance ESP32-S3-N16R8 microcontroller**
**-Affordable NRF24L01+ radio module for short comminications(Will be changed in future)**
**-1 Rotary Encoder**
**-1 100 microfarad electrolytic capacitor**
**-Male and female headers**
**-6x9 cm perfboard**
**-----New modules will be added and some of them could be changed due to various reasons in the future-----**
