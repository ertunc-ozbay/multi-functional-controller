# Multifunctional Controller Project(In Progress)

A custom handheld controller that built for both gaming and controlling RC devices.

**NOTE:** This project is still in development and some features and modules could be changed in the future. 

## FEATURES

* Low latency on both bluetooth and radio signal connection
* Long battery life
* 2 Universal USB-C connection port for portability
* High quality IPS screen
* Dual Hall-effect joysticks for long durability
* Haptic Feedback motors

* -----**New features will be added in the future**-----


## COMPONENTS

* ESP32-S3-N16R8 microcontroller
* NRF24L01+ radio module for short comminications(will be changed in future)
* 1 Rotary Encoder
* 2 Parallel connected 2400 mAh cell batteries(In total 4800 mAh)
* 1 100 microfarad electrolytic capacitor
* Male and female headers
* 6x9 cm perfboard
* 2 Passive Buzzers
* Haptic feedback motors
* WS2812B-8(NeoPixel Stick)

* ---**Some of them could be changed due to various reasons in the future**----
